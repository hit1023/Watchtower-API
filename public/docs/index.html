API REFERENCE / V0.1

Watchtower API

Webページの重要な変化を、検索・通知・AI連携に使える構造化イベントへ変換します。

BASE URLhttps://watchtower-api.s-quad.com

AUTHENTICATION

Bearer token

すべての/v1/エンドポイントでAPIキーが必要です。キーはURLやリクエスト本文に含めないでください。

Authorization: Bearer YOUR_WATCHTOWER_API_KEY
POST/v1/watches

監視を登録

URL、監視目的、実行間隔、重要度しきい値を登録します。実行間隔は15分以上です。

curl -X POST https://watchtower-api.s-quad.com/v1/watches \
  -H "Authorization: Bearer $WATCHTOWER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/pricing",
    "instruction": "料金と無料枠の変更だけを検出",
    "interval_minutes": 360,
    "importance_threshold": 0.7
  }'

Request fields

urlstring · required

公開HTTP/HTTPS URL

instructionstring · required

何を重要な変更とみなすか

interval_minutesinteger · default 60

15〜43,200分

importance_thresholdnumber · default 0.7

0〜1のイベント生成しきい値

GET/v1/watches

監視一覧

limitとcursorによるページングに対応しています。

curl "https://watchtower-api.s-quad.com/v1/watches?limit=25" \
  -H "Authorization: Bearer $WATCHTOWER_API_KEY"
POST/v1/watches/{id}/run

即時実行

定期スケジュールを待たず、指定した監視を実行します。初回は基準スナップショットを保存します。

{
  "data": {
    "watchId": "watch_…",
    "snapshotId": "snapshot_…",
    "changed": false
  }
}
GET/v1/events

変更イベント

watch_idを指定すると、単一監視のイベントだけを取得できます。

{
  "id": "event_…",
  "event_type": "meaningful_change.detected",
  "importance": 0.91,
  "category": "pricing",
  "summary": "無料枠が10,000件から5,000件に変更されました",
  "details": {
    "changes": [{ "before": "10,000", "after": "5,000" }],
    "url": "https://example.com/pricing"
  }
}

ERRORS

共通エラー

400

入力値またはURLが不正

401

APIキーがない、または一致しない

404

監視IDまたはパスが存在しない

413

取得対象のレスポンスが上限を超えた

502

監視対象URLを取得できない

SECURITY MODEL

安全な監視

ローカル・プライベートネットワークへのURLは拒否されます。リダイレクト先も再検証し、取得サイズとタイムアウトを制限しています。APIキーはCloudflare Secretとして保存されています。
